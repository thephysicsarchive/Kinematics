What the discriminant means physically
D > 0
The target line cuts the parabola twice. The ball reaches the same height once while rising and once while falling.
D = 0
The target line touches the parabola once. The two events merge at the maximum height.
D < 0
The target lies above the maximum height. There is no real time when the ball reaches it.
